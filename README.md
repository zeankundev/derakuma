# Derakuma

A lightweight FontoBene stroke-font parser for TypeScript — works in browsers, Node.js, Bun, Deno, and edge runtimes. Named after **Derakkuma** from maimai.

## Installation

```sh
npm i derakuma
# or
bun add derakuma
```
