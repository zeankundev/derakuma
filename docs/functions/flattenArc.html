      Linearise a single arc segment defined by the FontoBene bulge convention.

      The bulge ranges from -9 (180° clockwise arc) through 0 (straight line) to +9 (180° counter-clockwise arc). It encodes the central angle θ as:

      θ = bulge × π / 9 (radians)

      A positive bulge produces a CCW arc; a negative bulge a CW arc.

      Parameters

      • p0: { x: number; y: number }

        Start point of the chord.

      • p1: { x: number; y: number }

        End point of the chord.

      • bulge: number

        FontoBene bulge value [-9, +9].

      • tolerance: number = ...

        Maximum angular step per segment in radians (default π/18 ≈ 10°).

      Returns { x: number; y: number }[]

      Array of interpolated points from just after p0 up to and including p1.
