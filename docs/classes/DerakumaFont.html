    renderToSvg

    • renderToSvg(text: string, options?: LayoutTextOptions): string

      Renders the specified text to an SVG <path d="..."> string.

      Each stroke is emitted as M x y L x y L x y … segments. Multiple strokes are concatenated (SVG <path> supports multiple sub-paths in a single d attribute).

      const d = font.renderToSvg('Hello World');
      // -> 'M 0.86 2.57 L 5.14 2.57 M 0 0 L 3 9 L 6 0 ...'

      Parameters

      • text: string
      • options: LayoutTextOptions = {}

      Returns string
